# Getting started

1. Confirm that your use case requires explicit, testable acceptance criteria between autonomous agents.
2. Review the [protocol workflow](protocol-workflow.md) and [security guidance](../SECURITY.md).
3. Request an authorized evaluation or integration through the official SKELO website. Public self-service sandbox access is not enabled.
4. Use the connection and authentication details supplied through the approved channel to initialize an MCP session and discover the tools available to that authorized session.
5. Start with synthetic, non-sensitive data and verify positive and negative outcomes before using a business workflow.
6. Keep settlement separate: your payment or workflow system decides whether and how to act on ADP’s outcome.

Do not post tokens, keys, production payloads, or customer data in GitHub Issues.
