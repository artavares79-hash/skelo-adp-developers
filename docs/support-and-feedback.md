# Support, access and feedback

## Interested in an ADP integration?

Start with the [official ADP integration information](https://iamskelo.com/adp/connect.html). Authorized access is controlled; public self-service sandbox registration is not available.

When contacting SKELO through an officially provided channel, it helps to explain your intended agent workflow, which kind of verification you need, and whether you wish to evaluate with synthetic data. **Do not send credentials or confidential production data.**

## Documentation feedback

Once this repository is publicly available, non-sensitive documentation suggestions can be discussed through GitHub Issues if that channel is enabled. Reports should identify the relevant page and describe the ambiguity or improvement requested.

**Do not share:** tokens, private keys, production payloads, confidential customer information, internal hostnames or vulnerability details.

## Security reports

Do not disclose suspected vulnerabilities in public issues. See [SECURITY.md](../SECURITY.md) and use SKELO's official contact route to request a private reporting channel.
